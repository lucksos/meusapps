Política de Privacidade

Meus Apps (Fotos Sync e aplicativos relacionados). Última atualização: DATA_AQUI.

Quem somos

Os aplicativos “Meus Apps” são desenvolvidos e mantidos por LUCA DE SANTIS, para uso pessoal. Contato: luca.trattoria@gmail.com.

Quais dados do Google os apps acessam

  • Google Fotos (escopo photoslibrary.appendonly): o app apenas adiciona fotos e vídeos à biblioteca do usuário. Ele não lê, lista, altera nem apaga itens que já estão no Google Fotos.
  • Google Drive (escopo drive.file, quando aplicável): os apps acessam somente os arquivos que eles próprios criaram, como as notas.
  • Endereço de e-mail e identificação da conta (escopos openid e email): usados apenas para mostrar, dentro do app, qual conta está conectada.

Como os dados são usados

Os dados são usados exclusivamente para realizar a função pedida pelo usuário, como enviar fotos ao Google Fotos ou sincronizar notas com o Google Drive. Não há anúncios, análise de uso, venda, compartilhamento ou transferência de dados a terceiros.

Onde os dados ficam

Os aplicativos se comunicam diretamente com os serviços do Google a partir do aparelho do usuário. Não existe servidor próprio nem banco de dados externo. O token de acesso à conta Google, as configurações e o registro do que já foi enviado ficam armazenados somente no armazenamento privado do app, no próprio aparelho.

Retenção e exclusão

O usuário pode desconectar a conta a qualquer momento no app, o que apaga o token guardado no aparelho. Para revogar o acesso também no Google, basta remover o app em myaccount.google.com/permissions. Desinstalar o app apaga todos os dados locais. As fotos e os arquivos já enviados permanecem na conta Google do usuário até que ele mesmo os apague.

Uso dos dados de usuário do Google

O uso e a transferência, para qualquer outro app, de informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Alterações

Esta política pode ser atualizada. A data da última atualização aparece no topo desta página.
